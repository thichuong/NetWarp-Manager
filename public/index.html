Quản lý Wi-Fi & WARP
Theo Phong Cách Mới

Ứng dụng Desktop cao cấp, siêu mượt bằng Rust và Slint. Tự động khắc phục lỗi thư viện đồ họa lỗi thời và hỗ trợ cấu hình nâng cao chỉ với vài thao tác trực quan.

Tải bản Build (.tar.gz)
Dành cho Fedora 39/40/41+ (x86_64) • Kích thước: ~4.6 MB

Tính Năng Nổi Bật

Vượt qua webkit2gtk3

Khắc phục triệt để lỗi thiếu thư viện Webkit cũ trên Fedora. Tải và cài đặt Cloudflare WARP chính thức một cách an sau thông qua Terminal wizard tự động.

Khóa mạng Wi-Fi BSSID

Ép kết nối cố định vào một địa chỉ MAC (BSSID) cụ thể. Hỗ trợ đầy đủ Wi-Fi 6/6E (băng tần 6 GHz), loại bỏ hoàn toàn hiện tượng tự động nhảy trạm thu phát sóng (Mesh roaming).

Đo lường thời gian thực

Theo dõi sát sao tốc độ Download/Upload thực tế của card mạng thông qua procfs của Linux. Tự động kiểm tra độ trễ Ping liên tục tới Google và Cloudflare.

Console Logs & Toasts

Bảng nhật ký thu nhỏ tích hợp trực tiếp, giúp theo dõi chi tiết quá trình chạy lệnh ngầm. Hệ thống Toast Notification mượt mà thông báo trạng thái kết nối.

Hướng Dẫn Cài Đặt

1

Tải về và giải nén

Tải gói cài đặt nén `.tar.gz` từ nút Download ở trên, hoặc dùng lệnh sau để tải và giải nén trực tiếp trong terminal:

bash
# Tải gói cài đặt và giải nén $ wget -qO- https://thichuong.github.io/NetWarp-Manager/wiwarp-linux-amd64.tar.gz | tar -xz $ cd wiwarp-release
2

Chạy trình cài đặt

Khởi chạy script cài đặt bằng quyền quản trị `sudo`. Script sẽ cài đặt file thực thi vào thư mục `/opt/wiwarp`, tạo wrapper và biểu tượng launcher trên menu ứng dụng:

bash
# Cấp quyền thực thi và chạy script install $ sudo chmod +x install.sh && sudo ./install.sh
3

Mở ứng dụng

Sau khi cài đặt thành công, bạn có thể tìm kiếm ứng dụng **WiWarp** trong App Menu của hệ điều hành Fedora hoặc khởi chạy bằng cách gọi trực tiếp lệnh từ terminal:

bash
# Khởi chạy WiWarp $ wiwarp

Yêu Cầu Hệ Thống

Hệ điều hành tương thích

  • Fedora Workstation 39 / 40 / 41 trở lên.
  • Các bản phân phối dựa trên RPM (cấu hình NetworkManager & nmcli).

Thư viện đồ họa & Tiện ích

  • Yêu cầu NetworkManager và công cụ `nmcli` để quản lý Wi-Fi.
  • `fontconfig` và `openssl` (được cài đặt mặc định trên Fedora).
