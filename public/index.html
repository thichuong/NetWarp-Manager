Quick Start

1

Download & Extract

Download the `.tar.gz` package, or use the following command to download and extract directly in your terminal:

bash
# Download and extract the release package
$ wget -qO- https://thichuong.github.io/WiWarp/wiwarp-linux-amd64.tar.gz | tar -xz
$ cd wiwarp-release
2

Run Installer

Run the installation script with `sudo`. The script installs the executable to `/opt/wiwarp`, and creates a wrapper and desktop launcher icon in your applications menu:

bash
# Grant execution permissions and run the installer
$ sudo chmod +x install.sh && sudo ./install.sh
3

Launch Application

Once installed, find **WiWarp** in your Fedora Application Menu or launch it directly from the terminal:

bash
# Launch WiWarp
$ wiwarp

Uninstall (Optional)

If you ever need to remove the application system-wide, run the uninstaller script:

bash
# Run the uninstaller script with sudo
$ sudo /opt/wiwarp/uninstall.sh

Key Features

Fix WebKit Dependency

Completely resolves the missing legacy WebKit library issue on Fedora. Securely downloads and installs official Cloudflare WARP via an automated terminal wizard.

Wi-Fi BSSID Locking

Force a persistent connection to a specific MAC address (BSSID). Fully supports Wi-Fi 6/6E (6 GHz band), eliminating automatic mesh roaming.

Real-time Monitoring

Monitor real-time download/upload network speeds via Linux procfs. Automatically test ping latency to Google and Cloudflare continuously.

Console Logs & Toasts

Integrated mini-console log viewer to track background command execution. Smooth toast notifications for real-time connection status updates.

System Requirements

Compatible OS

  • Fedora Workstation 41+ (x86_64) or later.
  • RPM-based distributions (NetworkManager & nmcli configuration).

Graphics & Utilities

  • NetworkManager and nmcli tool required for Wi-Fi management.
  • `fontconfig` and `openssl` (installed by default on Fedora).
